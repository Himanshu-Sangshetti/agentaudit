Audit an AI agent before it goes live.

Point AgentAudit at an MCP server, a skill or an agent manifest. It checks every tool description, instruction and script, fills the registry record, and returns a governed verdict with evidence — nothing runs without a named owner.

Recorded real audits — no API calls, instant.

Shallow-cloned and read as text. Nothing from the repository is executed.

Nine endpoints, one verdict

Safety

Guard finds instructions hidden in tool descriptions, skills and READMEs. Inspect judges every script against the agent's declared scope. Protect finds secrets and personal data in prompts and configs.

Registry record

Extract pulls owner, systems and credentials verbatim with offsets. Fill writes the five-field registry record. Decide returns approve / needs owner / reuse / quarantine with probabilities.

Fact-checking

Verify checks README claims against the agent's real capabilities. Compare finds duplicate agents across the registry. Rerank points to an approved agent that already does the job.

Use it from the agentaudit CLI, as a GitHub Action that fails a PR on quarantine, or via POST /api/audit from an agent platform.
